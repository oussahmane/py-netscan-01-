# PyNetScan

A simple TCP port scanner written in Python.

## Features
- Scans common TCP ports
- Detects open ports
- Supports custom target IP addresses

## Requirements
- Python 3

## Usage

```bash
python3 netscan.py <IP>


Example:
python3 netscan.py 127.0.0.1
